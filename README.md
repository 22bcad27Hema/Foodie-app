# Foodie

A React Native (Expo) recipe app: browse recipes by category, view full details, favorite dishes, and publish, edit and delete your own recipes.

## Run it
- **Snack:** snack.expo.dev → Import Git Repository → paste this repo's public URL.
- **Locally:** `npm install` then `npx expo start`, and open in Expo Go.

## Features
- Horizontal category bar (14 categories plus Favorites and My Food)
- Recipe details: ingredients, instructions, prep time, servings, calories, difficulty
- Heart toggle to favorite and unfavorite
- My Food: add (photo upload, name, ingredients, steps), edit, delete
- Back button on every screen; favorites and your recipes are saved on the device

Recipes come from TheMealDB (needs an internet connection).
